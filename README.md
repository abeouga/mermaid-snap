# Mermaid Snap ワークベンチの手順書

kusakari-document（GitHub の abeouga/kusakari-usecase）の `.md` にある Mermaid の図を、1 つずつ開いて直し、「保存して次へ」で図のコードと PNG を書き戻す道具です。

## 別の PC で動かすまで

### 1. Node.js を入れる（初めての PC だけ）

https://nodejs.org/ja から LTS 版を入れます。npm のインストールは要りません。
入っているかは、PowerShell で次を実行すると分かります。v18 以上と表示されれば足ります。

```powershell
node -v
```

### 2. 2 つのリポジトリを同じ場所に clone する

```
（どこでもよいフォルダー。たとえばデスクトップ）
├─ mermaid-snap\        ← git clone https://github.com/abeouga/mermaid-snap.git
└─ kusakari-usecase\    ← git clone https://github.com/abeouga/kusakari-usecase.git
```

- 図のリポジトリのフォルダー名は `kusakari-usecase`（clone したままの名前）、`kusakari_document`、`kusakari-document` のどれでも見つけます。

### 3. 起動する

`mermaid-snap` の中の **`start-workbench.cmd` をダブルクリック**します。
黒い画面にリポジトリの場所が出て、ブラウザーでワークベンチが開きます。

- 黒い画面は、使っている間は閉じないでください。閉じるとワークベンチが止まります。
- リポジトリが隣に無いときは、そのフォルダーを `start-workbench.cmd` の上にドラッグ＆ドロップすると、そのリポジトリで起動します。
- ブラウザーが開かないときは、`http://127.0.0.1:8765/workbench.html` を自分で開きます。

## 使い方

1. 左の一覧で図を選ぶ（フォルダー → ファイル → 図。図が 1 つだけのファイルは、ファイル名を押すとその図が開く）。上の検索欄で、ファイル名・見出しで絞り込めます。
2. 右で直す。
   - コード欄でコードを書き換える。
   - 図の文字をダブルクリックして書き換える。クリックで選んで Backspace／Delete で消す（Ctrl+Z で戻す）。note は、文字か枠をクリックして Backspace／Delete で丸ごと消せる。シーケンス図の矢印をクリックすると、その矢印の文字を書ける（文字を全部消した矢印にも書ける）。
   - 「線を描く」で線を手で引く。表や線のラベルをドラッグで動かす。文字を選んで「中央ぞろえ」。
3. **「保存して次へ」（Ctrl+Enter）** を押す。次のことをしてから、次の図を開きます。
   - コードを変えていれば、`.md` のその図の中だけを書き換える。
   - 図の PNG を書き出して、`.md` の図の下の画像（`images/<ファイル名>-<番号>.png`）を置き換える。画像がまだ無ければ作って、`.md` に画像の行を足す。
4. 終わったら、リポジトリで変更を確かめて、自分で commit・push します（ワークベンチは commit しません）。

Ctrl+Z で 1 つ戻し、Ctrl+Y でやり直します。線や表の移動も、図の上での文字の書き換え・削除も、同じ順番で戻ります（コード欄に直接打ち込んだ分は、コード欄の中で Ctrl+Z）。

ほかのボタン：「保存」（Ctrl+S）、「前へ」（Ctrl+Shift+Enter）、「保存せず次へ」、「↻ 読み直す」（pull やブランチの切り替えの後に押す）、一覧の「◀ 折りたたむ」。

## 気をつけること

- **手で直した線や位置は、コードを変えると消えます。** 先にコードを直して保存し、そのあと線や位置を直して、もう一度保存します。
- 手で直した線や位置は、保存した PNG の中に入れてあります。別の PC で開いても、PNG があれば戻ります。
- ワークベンチを開いた後に、pull やブランチの切り替えで `.md` が変わると、上書きしないよう保存を断ります。「↻ 読み直す」を押してから直してください。
- ワークベンチは、この PC の中（127.0.0.1）からしか開けません。ほかの PC やスマートフォンからは開けません。

## 困ったとき

| 出たもの | すること |
| --- | --- |
| `Node.js が見つかりません` | 手順 1 の Node.js を入れ、黒い画面を開き直す |
| `リポジトリのフォルダーが見つかりません` | 手順 2 のとおり隣に clone するか、リポジトリのフォルダーを `start-workbench.cmd` にドラッグする |
| `ポート 8765 はほかのプログラムが使っています` | もう 1 つ起動していないか確かめる。別の番号で動かすなら PowerShell で `node serve.mjs --open --port 8766` |
| 図の文字が PC の字体になる | ネットにつながっていないと、日本語のフォント（Noto Sans JP）を読めません。図はそのまま使えます |

## フォルダーの中身

| ファイル | 役割 |
| --- | --- |
| `start-workbench.cmd` | ダブルクリックで起動する入口 |
| `serve.mjs` | ワークベンチのサーバー。リポジトリの `.md` と PNG を読み書きする |
| `workbench.html` | ワークベンチの画面（左に図の一覧、右に編集画面） |
| `mermaid-snap.html` | 図の編集画面。単体でブラウザーで開いても使える（PNG のコピー・保存） |
| `mermaid.min.js` | Mermaid 本体（11.4.1） |
| `snap.mjs` | コマンドで図を PNG・SVG にする道具（`node snap.mjs --help`） |
| `CLAUDE.md` | Claude 向けの詳しい説明 |
| `THIRD_PARTY_NOTICES.md` | 同梱している Mermaid のライセンス（MIT License） |
